# PoleTrack

PoleTrack — мобильный полевой помощник монтажника воздушных линий связи.

## MVP 0.1

- карта на MapLibre + OpenFreeMap;
- геолокация через стандартный Android LocationManager, без Google Play Services;
- старт и финиш линии;
- добавление опор по текущей GPS-точке;
- комментарий к каждой опоре;
- быстрые метки: «может упасть», сварка/муфта, ветки, переход дороги, вышка, запас кабеля;
- дополнительный запас кабеля на конкретной опоре;
- расчёт геометрической длины трассы;
- расчёт примерного расхода кабеля с процентом провиса и запасами на концах;
- расчёт остатка от бухты (по умолчанию 1000 м);
- предупреждение для линий 400–600 м и свыше 600 м;
- локальная история линий в SQLite;
- сервер и регистрация для MVP не нужны.

## Сборка

GitHub Actions автоматически собирает debug APK при push в main.
Артефакт сборки называется **PoleTrack-debug**.

Технологии: Kotlin, Jetpack Compose, MapLibre Native, Android API 26+.

> Карта сейчас использует OpenFreeMap. Перед коммерческим релизом инфраструктуру карт и условия использования нужно проверить под ожидаемую нагрузку.
